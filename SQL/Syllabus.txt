### 4. CRUD Operations

#### INSERT
```sql
INSERT INTO users (name, email) VALUES ('Tejas', 'test@mail.com');
```

#### SELECT
```sql
SELECT * FROM users;
```

#### UPDATE
```sql
UPDATE users SET name='Admin' WHERE id=1;
```

#### DELETE
```sql
DELETE FROM users WHERE id=1;
```

### 8. GROUP BY & HAVING
```sql
SELECT department, COUNT(*) 
FROM employees
GROUP BY department
HAVING COUNT(*) > 5;
```

### 9. Joins (VERY IMPORTANT 🔥)
- `INNER JOIN`
- `LEFT JOIN`
- `RIGHT JOIN`
- `FULL JOIN`
- Self Join

```sql
SELECT u.name, o.total
FROM users u
INNER JOIN orders o ON u.id = o.user_id;
```

### 10. Subqueries
- Single-row subquery

```sql

```

### 12. Views
```sql

```

### 13. Stored Procedures
```sql
CREATE PROCEDURE getUsers()
BEGIN
  SELECT * FROM users;
END;
```

### 14. Transactions
- `BEGIN`
- `COMMIT`
- `ROLLBACK`
- ACID properties

```sql
BEGIN;
UPDATE accounts SET balance = balance - 100 WHERE id=1;
UPDATE accounts SET balance = balance + 100 WHERE id=2;
COMMIT;
```
